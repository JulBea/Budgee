# @budgee/web

Application web de Budgee — React 19, TypeScript, Vite.

Voir le [README principal](../../README.md) pour la présentation du projet, l'architecture et les instructions d'installation.

## Scripts

```bash
npm run dev --workspace=apps/web       # serveur de dev (http://localhost:5173)
npm run build --workspace=apps/web     # typecheck + build de production
npm run lint --workspace=apps/web      # lint (oxlint)
npm run preview --workspace=apps/web   # prévisualisation du build
```
